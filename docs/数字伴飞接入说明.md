# 数字伴飞（Cyber Copilot）× AgentBridge 接入说明

> 适用对象：华东院数字伴飞（Cyber Copilot，基于 Hermes Agent 运行时）与本机 AgentBridge 桥的对接。
> 目标：让数字伴飞直接调用 AutoCAD / Rhino / SketchUp / Blender 的工具（读图、解释、建模），
> 全程不需要 DeepSeek，也不产生额外的模型费用。

---

## 一、两边的角色

| 组件 | 角色 |
|---|---|
| 数字伴飞（Cyber Copilot） | 上层 Agent：理解需求、规划步骤、决定画什么；运行时基于 **Hermes Agent**，支持挂载 MCP server |
| AgentBridge | 中间桥：把本机 CAD/建模软件的能力包装成 **3 个 MCP server**，并提供 REST API |
| 软件适配器 | 装在四个软件内部（AutoCAD .NET 插件 / Rhino 脚本 / SketchUp 扩展 / Blender 插件），由桥统一调度 |

数字伴飞已经在本机跑着 MCP（例如 `mcp__hdec_web_tools__web_search`），说明其 Hermes 运行时的 MCP 挂载链路是通的——接入 AgentBridge 只需要在 `config.yaml` 里追加 3 条 `mcp_servers`。

---

## 二、前提条件（一次性）

1. **软件侧**：AutoCAD / Rhino / SketchUp / Blender 打开，并已装好 AgentBridge 适配器。
   - 一键安装：让任意 Agent 调 `ab_install_adapter(host_kind="autocad|rhino|sketchup|blender")`，或在网页面板「软件配置」里点「连接」。
   - Rhino 每个会话需要执行一次：`_-RunPythonScript "%APPDATA%\McNeel\Rhinoceros\8.0\scripts\AgentBridgeHost_startup.py"`
   - AutoCAD 每个会话需要输入一次：`TESTCOPILOT`（插件随 AutoCAD 启动自动加载）
   - Blender / SketchUp 无需命令（适配器自动加载）
2. **桥侧**：确认桥在运行。打开面板（`runtime\open-panel.cmd` 或让 Agent 调 `ab_open_panel`），
   「总览」能看到四个软件「已连接」。

---

## 三、方式一（推荐）：在 Hermes 里挂载 MCP

### 3.1 配置位置

Hermes 的 MCP 配置在 **`~/.hermes/config.yaml`** 的 `mcp_servers` 键下：

- Windows：`C:\Users\<你的用户名>\.hermes\config.yaml`
- 官方文档：<https://hermes-agent.nousresearch.com/docs/user-guide/features/mcp>

> 注意：数字伴飞是 Hermes 的封装发行版，配置目录可能被改到其安装目下（如 `D:\Program Files\cyber-copilot\...`）。
> 若 `~/.hermes/config.yaml` 不存在，先在数字伴飞里执行一次 `hermes mcp` 让运行时生成配置，再按实际路径修改。

### 3.2 追加配置

把下面 3 个 server 追加到 `mcp_servers` 下。**路径改成你本机的插件安装路径**（可在网页面板
「Agent 接入」页直接复制，或见下方“如何拿到路径”）：

```yaml
mcp_servers:
  # ---- AgentBridge 桥接：3 个 MCP server ----
  agentbridge:
    command: "C:/Users/<你的用户名>/.dsh/profiles/desktop/node_modules/@local/agentbridge/runtime/python/python.exe"
    args: ["-m", "control_mcp"]
    cwd: "C:/Users/<你的用户名>/.dsh/profiles/desktop/node_modules/@local/agentbridge/runtime/copilot_backend"
    connect_timeout: 60
    timeout: 120
  hostmcp:
    command: "C:/Users/<你的用户名>/.dsh/profiles/desktop/node_modules/@local/agentbridge/runtime/python/python.exe"
    args: ["-m", "host_mcp", "--transport", "stdio"]
    cwd: "C:/Users/<你的用户名>/.dsh/profiles/desktop/node_modules/@local/agentbridge/runtime/copilot_backend"
    connect_timeout: 60
    timeout: 120
  cadmcp:
    command: "C:/Users/<你的用户名>/.dsh/profiles/desktop/node_modules/@local/agentbridge/runtime/python/python.exe"
    args: ["-m", "cadmcp", "--transport", "stdio"]
    cwd: "C:/Users/<你的用户名>/.dsh/profiles/desktop/node_modules/@local/agentbridge/runtime/copilot_backend"
    connect_timeout: 60
    timeout: 120
```

要点（来自 Hermes 官方文档）：

- stdio 传输键：`command` / `args` / `env` / `cwd`；`cwd` 支持相对或绝对路径。
- `connect_timeout` 约束 `initialize` 握手；首次启动 Python 较慢，建议 60 秒。
- 路径建议用**正斜杠 `/`**（YAML 里免转义）。
- 工具会以 `mcp__<server>__<tool>` 命名注册，例如：
  - `mcp__hostmcp__autocad_get_drawing_snapshot`
  - `mcp__hostmcp__rhino_create_box`
  - `mcp__agentbridge__ab_explain_drawing`
  - `mcp__agentbridge__ab_install_adapter`

### 3.3 如何拿到正确路径

在能访问桥的任意会话里，让 Agent 调用：

```
mcp__agentbridge__ab_open_panel        → 启动面板，返回 URL
```

或直接打开面板 → **「Agent 接入」** 页 → **「方式二」** 区块，复制其中的 `mcpServers`（Claude/Codex 格式），
把键名 `mcpServers` 改成 `mcp_servers`、`cwd` 原样保留即可用于 Hermes。

也可以下载 **「导出接入包」**（ZIP），里面包含 `mcp-config.json`、`hermes-mcp.yaml`、`test-agent.ps1`。

### 3.4 生效与验证

1. 重启数字伴飞的 Hermes 运行时（或在会话里执行 `/reload-mcp`）；
2. 新建对话，问一句：
   > 列出当前 AutoCAD 图纸的图层和实体统计。
3. 数字伴飞应当调用 `mcp__agentbridge__ab_explain_drawing` 或
   `mcp__hostmcp__autocad_get_drawing_snapshot`，返回图层/实体/门窗统计。

## 四、方式二（备选）：REST API

如果数字伴飞一侧不方便挂 stdio MCP，也可以直接走 HTTP（任何能发 HTTP 的 Agent 都行）。
先启动面板后端，然后调用：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/tools` | 工具名清单（约 22 个） |
| GET | `/hosts` | 宿主与工具详情 |
| POST | `/tool` | 执行任意工具（`tool_name` / `arguments` / `dry_run`） |
| GET | `/config/explain/drawing?host_kind=autocad` | 语义解释当前图纸 |
| GET | `/config/software/status` | 软件安装/运行/连接状态 |
| POST | `/config/hosts/{host_id}/connect` | 一键连接软件 |
| GET | `/config/agent/test` | 接入自检 |

示例（PowerShell）：

```powershell
$base = "http://127.0.0.1:8020"
Invoke-RestMethod "$base/tools"

# 读图（只读）
Invoke-RestMethod "$base/tool" -Method POST -ContentType "application/json" `
  -Body '{"tool_name":"autocad_get_drawing_snapshot","arguments":{}}'

# 预览写操作（拿票据）
Invoke-RestMethod "$base/tool" -Method POST -ContentType "application/json" `
  -Body '{"tool_name":"rhino_create_box","arguments":{"name":"Test","size":[2,2,2],"location":[0,0,0]},"dry_run":true}'
```

写操作协议：先 `dry_run=true` 拿 `permission_token` + `preview_hash`，再以相同票据提交；
提交返回 `rollback_token` 可回滚。

## 五、方式三（可选）：HTTP 方式的 MCP

AgentBridge 的 MCP server 同时支持 `streamable-http` 传输。若希望数字伴飞用 `url` 而不是 `command` 连接：

```powershell
# 在后台各起一个 HTTP 传输的 MCP server（端口自定）
& "<插件runtime>\python\python.exe" -m control_mcp --transport streamable-http --host 127.0.0.1 --port 8768
& "<插件runtime>\python\python.exe" -m host_mcp --transport streamable-http --host 127.0.0.1 --port 8767
& "<插件runtime>\python\python.exe" -m cadmcp --transport streamable-http --host 127.0.0.1 --port 8766
```

Hermes 侧：

```yaml
mcp_servers:
  agentbridge_http:
    url: "http://127.0.0.1:8768/mcp"
  hostmcp_http:
    url: "http://127.0.0.1:8767/mcp"
  cadmcp_http:
    url: "http://127.0.0.1:8766/mcp"
```

（注意：需要先把这三个进程常驻起来；用 stdio 方式则不需要额外进程。）

## 六、常见问题

| 现象 | 处理 |
|---|---|
| Hermes 启动后看不到 `mcp__hostmcp__*` 等工具 | 重启 Hermes 运行时或 `/reload-mcp`；确认 YAML 缩进正确（`mcp_servers` 下两级） |
| 连接超时 | 把 `connect_timeout` 提到 120；首次启动 Python 依赖较慢 |
| 工具返回 `connection_error` / `unknown_tool` | 软件没开或适配器没装：先在面板「总览」确认四个软件「已连接」 |
| 路径不对（`WinError 2`/找不到文件） | 用面板「Agent 接入」页复制的路径；或下载接入包里的 `hermes-mcp.yaml` |
| 提示需要额外授权 | AgentBridge 是本地桥，不需要 OAuth/API key |
