## 2. 人工标注格式

建议为每张快照准备同名 `expected.json`：

```json
{
  "semantic_counts": {
    "wall": 12,
    "door": 4,
    "window": 6,
    "unknown": 2
  },
  "require_outline": true,
  "outline_area": 125000000.0,
  "area_tolerance_ratio": 0.01,
  "unmapped_layers": ["0", "临时", "未知设备"]
}
```

数量必须按快照中的识别粒度标注。例如四条墙线会形成四个 `wall` 功能对象，不能把它们按一个房间记为一面墙。

## 3. 自动测试

### 3.1 导出快照

在 AutoCAD 内执行 `AISNAPSHOT`。命令会把完整 JSON 保存到 `%TEMP%\AgentBridge\snapshots\`，并在命令行显示路径。

### 3.2 运行验证器

```powershell
python .\scripts\validate_mvp_snapshot.py `
  "C:\path\D01.json" `
  --expected "C:\path\D01.expected.json" `
  --output "C:\path\reports\D01.report.json"
```

自动报告覆盖：

- 所有快照实体是否被识别或明确归入忽略项。
- 代理对象是否包含句柄、运行时类型和降级状态。
- 墙、门、窗、未知对象数量。
- 外围轮廓是否存在、面积是否在容差内。
- 未映射图层清单。
- 完整识别证据、置信度和图层建议。

## 4. AutoCAD 内人工验收

每张适用图纸至少执行一次：

1. 通过 Codex 调用图纸理解和功能对象识别，确认 MCP 返回与离线报告一致。
2. 调用外围轮廓 Skill，只生成预演时原图不得变化。
3. 确认后落图，必须只新增一条闭合多段线，Handle 可复验。
4. 执行 rollback，新增轮廓应被移除。
5. 调用图层统一建议，未知层不得被自动映射。
6. 选择 2 至 5 个映射执行，确认只影响当前空间，并可按当前空间中的指定 Handle 进一步限制。
7. 执行 rollback，实体应恢复到原图层。
8. 提交后手工修改一个受影响实体，再尝试 rollback；系统应拒绝覆盖更新工作。

## 5. 结果统计

对人工标注的支持范围分别统计：

```text
Precision = TP / (TP + FP)
Recall    = TP / (TP + FN)
```

必须分别报告 wall、door、window，并列出 `unsupported` 和 `needs_review`，不能从分母或失败清单中静默删除。

通过门槛：

- 连续 20 次 Codex MCP 任务成功率 ≥ 95%。
- 另一种模型/Host 连续 20 次任务成功率 ≥ 95%。
- 支持范围内墙、门、窗 Precision 和 Recall 均 ≥ 85%。
- 未支持对象显式报告率 100%。
- 外围轮廓和图层统一任务成功率均 ≥ 90%。
- 原图损坏事件 0；已提交写入可撤销率 100%。

## 6. 失败分级和开发裁决

| 等级 | 示例 | 处理 |
| --- | --- | --- |
| P0 | 原图损坏、未授权写入、回滚覆盖用户更新 | 立即停止测试并修复 |
| P1 | 代理对象静默丢失、错误对象被高置信度识别 | 当前迭代修复 |
| P2 | 特定块名未识别、复杂轮廓失败但有明确诊断 | 加入词典/适配器待办 |
| P3 | 提示文字、报告排序等体验问题 | 批量整理后处理 |

通过矩阵后进入第二阶段；若某类天正对象长期低于门槛，则缩小版本支持范围或采用转换副本，不阻塞普通线和块图纸交付。
