# AgentBridge 当前工作计划

更新日期：2026-07-24

## 当前阶段

第一阶段 MVP 的专业能力代码已经收口，但真实 DWG 验证暂不前置。当前先完成“连接器基座硬化”：保证 AutoCAD 2024 插件、`cadmcp`、Codex、其他 MCP Host、Planner 和多模型 provider 之间连接稳定、契约一致、诊断清楚。账号、积分、套餐和插件发布平台已经取消，不再作为连接前置条件或开发范围。

## 已完成能力

- AutoCAD 2024 插件、本地主线程桥和项目级 Codex MCP 接入。
- `cadmcp` 独立工具层，产品白名单为 13 个工具、4 个专业 Skill。
- OpenAI 兼容、Anthropic Messages 兼容及可配置 provider 适配。
- 图纸快照、图层、普通实体、块、动态块、自定义/代理对象摘要读取。
- 墙、门、窗、未知对象的统一功能识别。
- 外围闭合轮廓提取、面积计算和闭合多段线绘制。
- 图层映射建议与受控迁移。
- 写操作预览、一次性权限票据、原子事务、Handle 校验和显式回滚。
- 类天正工具、空间深化模型、旧阶段文档和发布平台资料移出开发目录。
- 插件登录、积分、套餐、用量和在线更新入口及契约移除。
- 插件模型选择已扩展为 OpenAI、Anthropic/Claude、DeepSeek、MiniMax、OpenAI Compatible、Ollama 和企业内网模型。
- `/connector/capabilities` 与 `/connector/diagnostics` 已提供五层诊断，桥协议固定为 `2.0`。
- 已完成任务可生成持久化的待审核 Skill 草稿；草稿工具必须属于 13 个产品白名单，且不会自动启用。
- 已增加 Skill 草稿编辑、校验和人工批准状态；批准后仍不自动启用。
- 已增加本地规范资料检索、来源引用核验和无来源拒答。
- 已增加一键连接器验收运行器和脱敏 JSON/Markdown 报告。

## 当前节点：C0-C3 连接器基座

### C0：产品表面清障（本轮）

- 插件不要求登录即可使用标准模式、智能体模式和自定义模型。
- 清除商业平台 API、DTO、配置项、积分回包和过期更新诊断。
- 设置页只保留连接方式、权限、服务地址、provider、模型和 API Key。
- 连接诊断调用 backend `/connector/diagnostics`，不依赖产品会话或发布平台。

### C1：契约与可观测性

- **代码及本机真实环境验证已完成：五层诊断总状态 `ok`。**
- 固化插件 ↔ backend、Host ↔ MCP、MCP ↔ 本地桥三段健康检查。
- 为初始化、工具发现、读取、dry-run、授权、提交、回滚定义统一错误码和 trace id。
- 诊断信息不得泄露 API Key、桥 token 或图纸敏感内容。
- 工具清单、JSON Schema、Skill 清单和桥路由加入自动契约测试。

### C2：Codex 与其他 Host 稳定性

- **Codex/CADMCP 20/20 初始化与工具发现通过；Claude Code 项目配置已完成，等待首次安全批准。**
- Codex 连续初始化、发现工具、读取快照各 20 次，无工具漂移。
- 至少另一种 MCP Host 完成同样测试。
- 模拟 Host 重启、MCP 重启、AutoCAD 未启动、桥 token 错误和超时恢复。
- stdio 为第一优先；Streamable HTTP 作为可选传输验证。

### C3：多模型与 Planner 稳定性

- **协议适配和插件入口已完成；当前 MiniMax 凭据在线验证返回认证失败，需更换有效凭据后完成 10 次门槛。**
- OpenAI 兼容与 Anthropic Messages 两类协议各验证一个真实 provider。
- 标准问答与 Planner 模式分别验证超时、限流、无效 Key、无效模型和非 JSON 响应。
- Planner 只能选择 13 个白名单工具，真实写入必须经过本地确认。
- 任务事件、重试、恢复、取消和 trace id 全链路可追踪。

## 连接器阶段通过门槛

- 自动化测试全绿，C# 编译 0 警告、0 错误。
- Codex 和第二 Host 的 MCP 初始化/工具发现成功率均不低于 95%。
- 连续 20 次快照读取成功率不低于 95%，失败有明确错误类别和恢复建议。
- 未授权真实写入为 0，白名单外工具发现为 0，敏感配置泄露为 0。
- 两类模型协议各至少完成 10 次标准请求和 10 次 Planner 请求。

## 下一节点：真实 DWG 验证与硬化

只有 C0-C3 达标后，才开始至少 10 张真实 AutoCAD 2024 / 天正 DWG 的验证：

- 读取完整性和对象支持状态；
- 墙、门、窗识别准确率与未知对象报告；
- 外围轮廓闭合率、面积误差和绘制位置；
- 图层迁移、提交校验和回滚可靠性；
- 失败快照沉淀为自动回归样本。

## 第二阶段进入条件

连接器门槛和真实 DWG 门槛同时通过后，才启动双线墙配对、中心线提取、门窗开口关系、补口后的围合空间识别及单线语义平面深化。未达标时优先修复连接或缩小支持范围，不增加无关功能。

六项目标的阶段裁决、已实现边界和下一轮验证清单见 [连接器、Agent 与 Skill 路线图](connector-agent-skill-roadmap-2026-07-24.md)。
